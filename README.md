# SPOKIY — сайт «труни для улюбленців на замовлення»

Сайт на украинском с переключателем на английский. Каталог по 4 типам животных
(кот, пёс, рептилия, грызун) по 5 моделей в каждом, калькулятор размера гроба
по весу, попап-оформление заказа, уведомления в Telegram и на почту,
письмо-подтверждение клиенту и админка для правки фото/размеров/цен/материалов/наличия.

# Этап 0. Запустить у себя на компьютере (30 минут)

Ничего подключать не надо — сайт уже работает, каталог берётся из файла,
заказы сохраняются в `data/orders.json`.

1. Установи **Node.js LTS** с https://nodejs.org (кнопка LTS, обычный установщик).
2. Распакуй папку проекта, например в `C:\pet-coffins`.
3. Открой в этой папке терминал: в проводнике зайди в папку, в адресной строке
   напиши `powershell` и нажми Enter.
4. Скопируй `.env.example` в `.env`:
   ```powershell
   copy .env.example .env
   ```
   Открой `.env` блокнотом и поменяй `ADMIN_PASSWORD` на свой пароль.
5. Установи зависимости и запусти:
   ```powershell
   npm install
   npm run dev
   ```
6. Открой http://localhost:3000 — это сайт. И http://localhost:3000/admin — админка
   (пароль из `.env`).

> Пока не подключены Telegram и почта, заказ всё равно оформляется и виден
> в админке во вкладке «Замовлення».

# Этап 1. Выложить сайт в интернет (Vercel, бесплатно)

1. Зарегистрируйся на https://github.com — создай пустой репозиторий, например `pet-coffins`.
2. Загрузи туда файлы проекта (кнопка **Add file → Upload files**, папку `node_modules`
   загружать не нужно — её нет в архиве).
3. Зарегистрируйся на https://vercel.com через GitHub → **Add New → Project** →
   выбери репозиторий → **Deploy**. Настройки менять не нужно, Vercel сам поймёт Next.js.
4. В Vercel открой проект → **Settings → Environment Variables** и добавь всё,
   что у тебя в `.env` (пока это `ADMIN_PASSWORD` и контакты). После добавления
   переменных нажми **Deployments → … → Redeploy**.

Готово, у сайта появится адрес вида `pet-coffins.vercel.app`.

> Важно: на Vercel файл `data/orders.json` не сохраняется между запусками —
> заказы будут приходить в Telegram и на почту, но список в админке будет пустым,
> пока не сделаешь Этап 4 (Supabase). Порядок этапов 2 → 3 → 4 как раз про это.

# Этап 2. Telegram-бот — уведомления о заказах

1. В Telegram напиши боту **@BotFather** → команда `/newbot` → придумай имя и username.
   Он пришлёт **токен** вида `8123456789:AAF...`.
2. Напиши что-нибудь своему новому боту (просто «привет») — без этого он не сможет
   тебе писать.
3. Узнай свой chat id: напиши боту **@userinfobot**, он ответит числом — это `TELEGRAM_CHAT_ID`.
4. Впиши в `.env` (и в Vercel → Environment Variables):
   ```
   TELEGRAM_BOT_TOKEN=8123456789:AAF...
   TELEGRAM_CHAT_ID=123456789
   ```
5. Перезапусти (`npm run dev`) или сделай Redeploy в Vercel. Оформи тестовый заказ —
   в Telegram придёт вся карточка заказа.

> Хочешь, чтобы заказы падали в общий чат с сотрудником: создай группу, добавь туда
> бота, и в качестве `TELEGRAM_CHAT_ID` укажи id группы (начинается с `-100...`).

# Этап 3. Почта — письмо тебе и подтверждение клиенту

Самый простой вариант — Gmail.

1. В Google-аккаунте включи **двухэтапную аутентификацию**
   (https://myaccount.google.com/security).
2. Там же создай **пароль приложения** (App password) — Google даст 16 символов.
   Это НЕ твой обычный пароль от почты.
3. Впиши в `.env` и в Vercel:
   ```
   SMTP_HOST=smtp.gmail.com
   SMTP_PORT=465
   SMTP_SECURE=true
   SMTP_USER=твоя_почта@gmail.com
   SMTP_PASS=шестнадцать_символов_от_google
   MAIL_FROM="SPOKIY <твоя_почта@gmail.com>"
   OWNER_EMAIL=твоя_почта@gmail.com
   ```
4. Заодно заполни реквизиты — их клиент увидит после заказа и получит в письме:
   ```
   NEXT_PUBLIC_PAYMENT_DETAILS=ФОП Прізвище Ім'я / IBAN UA00 0000 ...
   ```
5. Перезапусти. Тестовый заказ → тебе приходит письмо с заказом, клиенту —
   красивое подтверждение с размером, ценой и реквизитами.

> Если позже захочешь письма с собственного домена (`zamovlennya@твойдомен.ua`) —
> подключается так же, только SMTP-данные возьмёшь у своего хостинга почты.

# Этап 4. Supabase — база товаров, заказов и фотографий

Нужен для двух вещей: чтобы правки в админке сохранялись навсегда и чтобы
можно было **загружать фото** гробов кнопкой, а не ссылкой.

1. Зарегистрируйся на https://supabase.com → **New project** (регион EU, бесплатный план).
2. Открой **SQL Editor → New query**, вставь целиком содержимое файла `supabase.sql`
   и нажми **Run**. Это создаст таблицы и хранилище для фото.
3. Открой **Project Settings → API** и скопируй:
   - `Project URL` → в `NEXT_PUBLIC_SUPABASE_URL`
   - ключ **`service_role`** (секретный!) → в `SUPABASE_SERVICE_ROLE_KEY`
   ```
   NEXT_PUBLIC_SUPABASE_URL=https://xxxx.supabase.co
   SUPABASE_SERVICE_ROLE_KEY=eyJhbGci...
   SUPABASE_BUCKET=coffins
   ```
   > Ключ `service_role` нигде не публикуй — он даёт полный доступ к базе.
4. Залей стартовый каталог в базу (один раз):
   ```powershell
   node scripts/push-to-supabase.mjs
   ```
5. Добавь те же три переменные в Vercel и сделай Redeploy.

Теперь в админке работает загрузка фото, а все правки и заказы хранятся в базе.

# Этап 5. Свой домен

1. Купи домен (например на `hostiq.ua`, `namecheap.com` или `cloudflare.com`).
2. В Vercel: **Settings → Domains → Add** → впиши домен.
3. Vercel покажет две DNS-записи — добавь их в панели регистратора.
   Через 15–60 минут домен заработает, сертификат Vercel выпустит сам.

## Как пользоваться админкой

Адрес: `твойсайт/admin`, пароль — из `ADMIN_PASSWORD`.

- **Товары** — вкладки по типу животного. У каждой модели можно поменять
  название и материал (укр + англ), описание, диапазон длины, цену и наличие.
  После правок обязательно **«Зберегти»**.
- **Фото** — кнопка под картинкой (работает после Этапа 4). Либо вставь ссылку
  на фото в поле внизу карточки.
- **Цена считается так:** `цена = «Ціна за базову» + (нужная длина − «Базова довжина») × «Доплата за 1 см»`.
  То есть достаточно задать цену для типового размера и надбавку за сантиметр —
  калькулятор сам посчитает цену под конкретное животное.
- **Замовлення** — все заказы, статус можно менять (Новий / В роботі / Виконано / Скасовано).

## Как работает калькулятор

Размер тела считается по весу: `длина ≈ k × ∛вес`, где `k` свой у каждого вида
(рептилии длиннее и уже, грызуны компактнее). Дальше добавляется запас на подстилку,
ширина и высота берутся как доля длины. Все коэффициенты — в начале файла
`lib/calc.ts`, в объекте `SHAPES`; если по опыту размеры надо подправить —
менять нужно только там.
